# UCDH flextable theme

Applies UC Davis Health styling to a flextable, using the UCDH navy and
gold colors.

## Usage

``` r
theme_flextable_ucdh(x)
```

## Arguments

- x:

  A flextable object.

## Value

A flextable with UCDH styling applied.

## References

[UC Davis Health Graphic Standards:
Colors](https://health.ucdavis.edu/graphic-standards/colors/) \# nolintr

  theme_flextable_ucdh()
