# Constructor for basic_summaries Result

Constructor for basic_summaries Result

## Usage

``` r
new_basic_summaries_result(tbl_gt, raw_table, figures)
```

## Arguments

- tbl_gt:

  A `gt_tbl` object created from the summary table.

- raw_table:

  A `gtsummary` table object before gt conversion.

- figures:

  A named list of ggplot figures generated by variable.

## Value

A `basic_summaries_result` S7 object.
