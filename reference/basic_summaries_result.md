# basic_summaries Result Class

S7 class for
[`basic_summaries()`](https://ucdavis.github.io/bsu.tools/reference/basic_summaries.md)
output.

## Usage

``` r
basic_summaries_result(tbl_gt = NULL, raw_table = NULL, figures = list())
```

## Arguments

- tbl_gt:

  A `gt_tbl` object created from the summary table.

- raw_table:

  A `gtsummary` table object before gt conversion.

- figures:

  A named list of ggplot figures generated by variable.

## Value

An S7 class object.
